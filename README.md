Üç Ədədin Cəminin Müqayisəsi 

Layihə haqqında
İstifadəçidən üç ədəd alır, cəmini hesablayır və nəticəni 20 ilə müqayisə edir.

Xüsusiyyətlər
- Daxil edilən məlumatların yoxlanılması.
- Yanlış məlumat daxil edildikdə təkrar sorğu.
- Ədədlərin cəminin hesablanması.
- Nəticənin 20 ilə müqayisəsi.

İstifadə olunan anlayışlar
`while`, `for`, `if/elif/else`, `input()`, `isdigit()`, `int()`, List.

İşə salınması
```bash
python ededlerin_muqayisesi.py
```
